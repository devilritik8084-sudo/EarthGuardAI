# 🌍 EarthGuardAI

### AI Disaster Prediction & Emergency Alert System

EarthGuardAI is an educational AI/ML project that analyzes environmental conditions and predicts a disaster-risk level using a Decision Tree Classifier.

## 🤖 AI/ML Model

- Machine Learning Algorithm: Decision Tree Classifier
- Programming Language: Python
- ML Library: Scikit-learn
- Data Processing: Pandas

### Input Features

- Temperature (°C)
- Rainfall (mm)
- Wind Speed (km/h)

### Output

The system predicts:

- 🟢 LOW Risk
- 🟡 MEDIUM Risk
- 🔴 HIGH Risk

## ✨ Features

- AI-based disaster-risk prediction
- Environmental condition analysis
- Prediction history
- Date and time recording
- Interactive command-line interface
- Model information section
- Educational/research prototype
